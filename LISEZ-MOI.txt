AKEED - Site Fournisseurs (Bornes multifonction, POS & imprimantes)
Prod by Oussema Jl
===================================================================

OUVRIR LE SITE
  Double-clic sur "index.html" (ou "Ouvrir le site.bat").
  Fonctionne hors ligne, dans Chrome / Edge.
  Le site demande un MOT DE PASSE : les donnees (prix, fournisseurs, remarques)
  sont chiffrees dans assets\js\data.enc.js et illisibles sans ce mot de passe.
  Fermer l'onglet ou cliquer sur le bouton de deconnexion = deconnexion.

MOT DE PASSE
  Changer le mot de passe : double-clic sur "Changer le mot de passe.bat".
  Le mot de passe est garde seulement sur ce PC (outils\.motdepasse),
  il n'est jamais envoye sur GitHub. Ne pas partager ce fichier.
  Attention : les photos / videos / PDF du dossier data\ ne sont PAS chiffres.

CONTENU DU DOSSIER
  index.html                 -> page d'accueil du site
  assets\                    -> logo, style, scripts, photos extraites de l'Excel
  data\                      -> COPIE du dossier Fournisseurs_Bornes_Multifonction
                                + copie du tableau Excel (les originaux du Bureau ne sont pas touches)
  outils\generer_site.py     -> script de generation

METTRE A JOUR APRES MODIFICATION DE L'EXCEL OU DU DOSSIER
  Double-clic sur "Mettre a jour le site.bat"
  (recopie les donnees du Bureau et regenere le site).
